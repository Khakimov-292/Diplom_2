Чтобы запустить все тесты нужно выполнить команду:

PYTHONPATH=. pytest tests/*

Список тестов

1.Создание пользователя: 
2. Создание уникального пользователя
3. Создание пользователя, который уже был зарегистрирован 
4. Создание пользователя без указания обязательного поля

Авторизация пользователя:
1. Авторизация с валидными учетными данными 
2. Авторизация с невалидными учетными данными
Изменение данных пользователя: 
1. Изменение данных пользователя с авторизацией 
2. Изменение данных пользователя без авторизации
Создание заказа: 
1. Создание заказа с авторизацией и ингредиентами 
2. Создание заказа без авторизации 
3. Создание заказа без ингредиентов 
4. Создание заказа с неверным хешем ингредиентов
Получение заказов пользователя: 
1. Получение заказов авторизованного пользователя 
2. Получение заказов не авторизованного пользователя
